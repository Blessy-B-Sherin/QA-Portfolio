# Test Plan - Flipkart E2E Testing

| Section                     | Content                                                                                   |
|------------------------------|-------------------------------------------------------------------------------------------|
| **Project Name**             | Flipkart E2E Testing                                                                      |
| **Test Plan ID**             | TP_Flipkart_001                                                                           |
| **Prepared By**              | Blessy B Sherin                                                                           |
| **Date**                     | 13/10/2025                                                                                |
| **Version**                  | 1.0                                                                                        |
| **Scope**                    | Manual testing of Flipkart website including login, search, add to cart, and checkout functionality. |
| **Out of Scope**             | Payment gateway integration, backend performance, admin panel testing                     |
| **Objectives**               | Ensure application functionality, usability, and reliability.                             |
| **Test Strategy / Approach** | Testing will follow a manual functional approach. Test cases will be executed sequentially. Defects will be logged with severity and priority in the Bug Report template. |
| **Testing Types**            | Functional Testing, UI Testing, Regression Testing                                        |
| **Environment**              | Browser: Chrome, Firefox; OS: Windows 10; Internet connection                              |
| **Test Data Requirements**   | Valid user accounts, sample products for search and cart, delivery addresses              |
| **Roles & Responsibilities** | Tester: Blessy; Reviewer: QA Lead                                                        |
| **Deliverables**             | Test Cases, Bug Reports, Test Summary                                                    |
| **Entry Criteria**           | Application deployed, test data available, test environment ready                        |
| **Exit Criteria**            | All planned test cases executed, all critical/high severity bugs resolved                 |
| **Severity & Priority Definitions** | - Critical: System crash or major functionality broken<br>- High: Major feature not working, blocks workflow<br>- Medium: Minor functionality issue, workaround available<br>- Low: Cosmetic issues, typos, UI misalignment |
| **Risks & Assumptions**     | Test environment may be unstable; Some modules may not be available for testing           |
| **Communication & Reporting** | Daily status updates to QA Lead. Critical/High severity bugs reported immediately.       |
| **Approval / Sign-off**      | Test Plan will be approved by QA Lead before execution begins                             |
