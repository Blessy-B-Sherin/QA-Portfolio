# Manual Testing - Flipkart Website

This folder contains **manual testing artifacts** for Flipkart e-commerce flow, including test plan, test cases, and bug reports.

### 📄 Test Artifacts
| File | Description |
|------|-------------|
| [TestPlan.md](Manual-Testing/TestPlan.md) | Complete testing strategy and objectives in Markdown format |
| [TestCases.md](Manual-Testing/TestCases.md) | Detailed functional test cases in Markdown table |
| [BugReport.md](Manual-Testing/BugReport.md) | Documented defects discovered during manual testing |

### ⚡ Scope
- Login / Signup
- Product Search
- Add to Cart
- Checkout

### 🔹 Notes
- All Markdown files are formatted for **direct viewing on GitHub**.
- Original `.docx` or `.xlsx` versions are available in the folder for download if needed.
